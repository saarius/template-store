# Merchant telemetry and static audits

The public dashboard reads `/var/lib/backroadbum/telemetry.json` on the server. `experiment-report/telemetry.ts` validates a small projection before rendering; unknown fields are omitted, malformed optional sections become unavailable and invalid sample timestamps reject the sample. Missing values never become zero. Checkout history dates and paired ending state/time are checked before formatting, and future sample times are stale, not fresh readiness evidence. The existing archive-recovery helper validates its own shape separately.

`source-type-audit.mjs` uses the pinned Astro parser for frontmatter, expressions and scripts, and TypeScript syntax for other source files. It rejects explicit `any` types and invalid syntax, not ordinary comments, prose, string literals or properties named `any`. The two historical OFL license copies retain their exact upstream bytes: the text audit recognizes only their named SHA-256 digests; edits and other paths still receive the normal whitespace check.

Run the complete quick gate with `.nvmrc`'s **Node 24.22.0** and pinned pnpm. The artifact workflows intentionally reject a different patch version even though the storefront supports the broader Node24 engine range. On this 2GB merchant host, `NODE_OPTIONS=--max-old-space-size=1536 pnpm verify:quick` passes serially; lower600/1024MiB typecheck heaps were insufficient. Do not change the toolchain checks or increase browser concurrency to hide that constraint.

Targeted tests are `tests/unit/backroadbum-telemetry.test.ts` and `tests/workflows/source-audits.test.mjs`. Disposable built-site checks use a private network namespace, copied SQLite and a **directory** bind for synthetic telemetry; the live collector atomically replaces its file, so a file-only bind is not stable for fixture mutation. Never corrupt the live telemetry, replay payment/label drivers or expose raw collected input as proof. November15 evidence is in workspace `evidence/2026-11-15-merchant-audits/`.
