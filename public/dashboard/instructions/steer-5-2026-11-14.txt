### 3. Track 2 — Configure Native EmDash Cloudflare Email Relay & Dogfood Shopper OTP Accounts End-to-End
- **Provisioned HTTPS Email Relay + Test Inbox (`/etc/backroadbum/email.env`):**
  - Linode blocks outbound SMTP (`25`/`465`/`587`), so we provisioned a dedicated Cloudflare Email Routing + `send_email` + KV Worker over `HTTPS (443)` and wired `EnvironmentFile=-/etc/backroadbum/email.env` (`root:agent`, `0640`) into both `backroadbum.service` and `trialrun.service` (`trialrun-run` automatically redacts `BACKROADBUM_EMAIL_RELAY_TOKEN` from logs):
    - `BACKROADBUM_EMAIL_RELAY_URL=https://backroadbum-email.tsaari71.workers.dev`
    - `BACKROADBUM_EMAIL_RELAY_TOKEN=<secret>` (never print, echo, log, commit, screenshot, or expose in git, PRs, or `/dashboard/`)
    - `BACKROADBUM_EMAIL_FROM=noreply@backroadbum.com`
    - `BACKROADBUM_TEST_SHOPPER_EMAIL=shopper-test@backroadbum.com`
  - **Worker HTTP endpoints** (use Node `fetch` or `curl`—avoid default `Python-urllib` `User-Agent`, which Cloudflare blocks with `403`):
    - `GET $BACKROADBUM_EMAIL_RELAY_URL/health` → unauthenticated `{ ok: true, service: "backroadbum-email" }`.
    - `POST $BACKROADBUM_EMAIL_RELAY_URL/send` with header `Authorization: Bearer $BACKROADBUM_EMAIL_RELAY_TOKEN` and JSON `{ from: { name, email }, to, subject, text, html?, replyTo?, cc? }` → sends real DKIM/SPF-signed `@backroadbum.com` mail via Cloudflare `send_email`.
    - `GET $BACKROADBUM_EMAIL_RELAY_URL/inbox?to=shopper-test@backroadbum.com` with `Authorization: Bearer $BACKROADBUM_EMAIL_RELAY_TOKEN` → returns `{ ok: true, to, count, messages: [{ id, from, to, subject, messageId, receivedAt, decoded }] }` (1-hour KV TTL; `decoded` contains the delivered MIME text/HTML).
    - `DELETE $BACKROADBUM_EMAIL_RELAY_URL/inbox?to=shopper-test@backroadbum.com` with `Authorization: Bearer $BACKROADBUM_EMAIL_RELAY_TOKEN` → clears consumed test OTP messages from KV.
